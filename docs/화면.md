# 화면별 안내

사이드바의 열다섯 화면이 각각 무엇을 하는지, 무엇이 필요하고 무엇이 필요 없는지.

준비물이 있는 화면은 **⚙︎** 로 표시했고, 그 설정 방법은 [설정 안내](설정.md)에 있습니다. 표시가 없는 화면은 내려받아 빌드하면 바로 됩니다.

- [시작](#시작) · [문서](#문서) · [미디어](#미디어) · [음악](#음악) · [변환](#변환) · [자동화](#자동화)

## 시작

### 개요 `⌘1`

지금 이 Mac에서 무엇이 도는지, 무엇이 준비되어 있고 무엇이 빠졌는지를 한 화면에 모읍니다. 위쪽 카드 다섯 개가 브리핑 상태·녹음 개수·받아쓰기 단축키·음악·프린터를 요약하고, 그 아래에 **오늘 마감**과 **밀린 것**이 옵니다. 마지막 정리에서 실패한 소스가 있으면 그 사유가 첫 화면에 그대로 뜹니다 — 조용히 빠진 소스를 모른 채 지나가지 않게 하려는 것입니다.

> 이 화면의 사진은 싣지 않았습니다. 실제 메일 제목과 마감이 그대로 나오는 화면이라, 공개 저장소에 올릴 것이 아닙니다.

## 문서

### 문서 인식 `⌘2`

![문서 인식](images/app-documents.png)

강의 슬라이드를 찍은 사진, 스캔한 유인물 PDF, 또는 화면의 일부를 글자로 바꿉니다. 위쪽에서 두 방식 중 하나를 고릅니다.

- **빠름** — macOS에 들어 있는 Vision을 씁니다. 준비물이 없고 즉시 끝납니다.
- **정밀 (수식·표)** ⚙︎ — MinerU가 수식을 LaTeX로, 표를 표로 살린 Markdown을 만듭니다. `scripts/setup-docparse-env.sh`가 필요합니다.

툴바의 `화면 영역 캡처`를 누르면 화면에서 직접 영역을 골라 바로 인식합니다. 어느 쪽을 고르든 이미지가 이 Mac을 벗어나지 않습니다.

### 스캔 보정 `⌘3`

![스캔 보정](images/app-scan.png)

비스듬히 찍은 유인물 사진을 반듯하게 펴고, 그늘과 얼룩을 지워 스캔한 것처럼 만듭니다. 네 귀퉁이를 자동으로 찾고, 틀리면 직접 끌어 고칠 수 있습니다. 여러 장을 한 PDF로 묶어 냅니다.

### PDF 편집 `⌘4`

![PDF 편집](images/app-pdf.png)

여러 PDF를 드롭하면 넣은 순서대로 합칩니다. 쪽을 지우고 돌리고 순서를 바꾸고, 범위를 잘라 새 파일로 냅니다. 암호를 걸거나 풀 수 있고, 서명 이미지와 워터마크를 얹을 수 있습니다.

### 프린트 `⌘P` ⚙︎

![프린트](images/app-print.png)

집에 둔 서버에 USB로 붙은 프린터로 보냅니다. **설정하지 않으면 사진처럼 아무것도 하지 않고**, 다른 기능에는 영향이 없습니다.

설정한 뒤에는 PDF·사진·문서(한글 포함)를 드롭하면 됩니다. 이 화면의 특징은 **미리보기가 실제로 나갈 파일 그대로**라는 것입니다 — 쪽 범위·모아찍기·회전을 프린터가 아니라 이 Mac에서 파일에 먼저 적용하고, 그 파일을 그려서 보여 줍니다. 종이가 몇 장 나갈지도 누르기 전에 셉니다. 집에서든 밖에서든 적어 둔 두 주소를 순서대로 시도합니다.

## 미디어

### 녹음·전사 `⌘5` ⚙︎

앱에서 바로 녹음하거나, 오디오·영상 파일을 드롭하거나, 강의 영상 주소를 붙여넣으면 오디오만 내려받아 한국어 전사를 만듭니다. 타임스탬프가 붙고, 토큰을 넣어 두면 누가 말했는지도 가릅니다.

녹음마다 이름과 과목·주제 태그를 달아 두면 나중에 태그로 묶어 볼 수 있습니다. 여러 전사와 AI 자동요약은 대기열에 넣은 순서대로 하나씩 처리됩니다.

`scripts/setup-transcription-env.sh`가 필요합니다.

> 이 화면의 사진도 싣지 않았습니다. 녹음 보관함에 실제 녹음 목록이 그대로 나옵니다.

### 소리 다듬기 `⌘6` ⚙︎

![소리 다듬기](images/app-audiocleanup.png)

강의·회의 녹음에서 에어컨 소리와 웅성거림을 걷어내고 음량을 고르게 맞춥니다.

- **빠름 (내장)** — 스펙트럼 게이트. 준비물이 없습니다.
- **정밀 (AI 모델)** — SepFormer 음성 분리 모델이 사람 목소리만 남깁니다. 변하는 잡음까지 잡지만 16 kHz 모노로 나옵니다. `scripts/setup-media-env.sh`가 필요합니다.

영상을 넣으면 소리만 꺼내 다듬습니다.

### 누끼 따기 `⌘7` ⚙︎

![누끼 따기](images/app-cutout.png)

사진을 드롭하면 배경을 지운 투명 PNG를 만듭니다. 배경을 투명 대신 특정 색으로 채울 수도 있습니다. 모델은 이 Mac에서만 돌고 사진은 기기를 벗어나지 않습니다.

`scripts/setup-matting-env.sh`가 필요합니다.

### 화질 올리기 `⌘8` ⚙︎

![화질 올리기](images/app-upscale.png)

작거나 흐린 사진을 크고 또렷하게 만듭니다. 뒷자리에서 찍은 슬라이드나 저해상도 스캔에 씁니다.

`scripts/setup-media-env.sh`가 필요합니다(소리 다듬기와 같은 환경).

## 음악

### 음악 `⇧⌘M` ⚙︎

![음악](images/app-music.png)

곡을 찾아 내 플레이리스트를 만들되, **소리는 광고가 없는 곳에서만** 냅니다.

- **찾기** — YouTube에서 검색합니다. Data API 키가 필요하고, 사진처럼 키가 없으면 그렇게 말합니다.
- **재생** — 이 Mac의 음악 파일 → Audius → Internet Archive 순서로 같은 곡을 찾아 그것으로 냅니다. 셋 다 없으면 직접 고르거나 YouTube 폴백으로 재생하고, 어느 경로로 났는지 목록에 적힙니다.

키가 없어도 **무료 음원 검색**과 **내 음악**은 그대로 됩니다. 계정은 없고 보관함은 이 Mac의 파일 하나입니다.

## 변환

### 용량 줄이기 `⌘9`

![용량 줄이기](images/app-compression.png)

사진·PDF·영상의 용량을 줄입니다. 3단계로 고르거나, **목표 용량**을 적어 그 밑으로 맞출 수도 있습니다(제출 용량 제한이 있을 때 씁니다). 원본은 그대로 남고 파일은 기기를 벗어나지 않습니다.

### 형식 변환 `⌘0`

![형식 변환](images/app-convert.png)

사진·오디오·영상·문서를 다른 형식으로 바꿉니다. 넣은 파일에 맞춰 종류가 자동으로 바뀝니다.

**한글 문서(HWP 5.x·HWPX)를 아무것도 설치하지 않아도 앱이 직접 읽습니다.** 다만 다시 조판하므로 쪽 나눔과 서식이 원본과 달라집니다. 서식 그대로가 필요하면 `scripts/setup-hwp.sh`를 실행하세요(LibreOffice + H2Orestart 경로). DOCX·PPTX·XLSX는 LibreOffice가 있어야 합니다.

## 자동화

### 자동 브리핑 `⌘B` ⚙︎

![자동 브리핑](images/app-briefing.png)

메일·메시지·캘린더·학교 공지·eTL을 읽기 전용으로 모아 이 Mac의 모델로 정리합니다. 이 화면은 결과가 아니라 **상태**를 보여 줍니다 — 새 항목 수집 → 로컬 모델 분류 → 보관함에 저장 → 모델 언로드의 네 단계가 어디까지 갔는지, 마지막 성공이 언제였는지.

사진 아래쪽의 `명시적 실행을 기다리고 있습니다`가 이 앱의 기본 상태입니다. **눌러야 돕니다.** 밤에 스스로 한 번 도는 것은 설정에서 켤 때만이고, 그때도 전원이 꽂혀 있고 노트북이 열려 있고 한동안 아무것도 누르지 않았을 때만 시작합니다.

소스마다 준비물이 다릅니다 — [설정 안내](설정.md)의 Gmail·eTL·Slack 항목을 보세요. 준비하지 않은 소스는 0건으로 빠지고 나머지는 그대로 돕니다.

### 브리핑 보관함 `⇧⌘B`

정리된 결과가 날짜별로 쌓입니다(최근 90일). `오늘 꼭 할 일` / `확인해야 할 것` / `기타` 세 칸이고, 각 항목은 어느 소스에서 왔는지와 마감이 언제인지를 함께 답니다.

- 끝낸 일에 체크하고 메모를 답니다.
- 잘못 분류된 항목은 **한 칸씩** 옮깁니다(두 칸을 건너뛰지 않습니다).
- 그 항목만 다시 분석시킬 수 있습니다.
- 항목을 Mac 캘린더나 미리 알림으로 넘깁니다.
- 보관된 모든 날에서 검색합니다.

> 사진 없음 — 실제 메일 제목이 그대로 나오는 화면입니다.

### 일정 달력 `⌥⌘B`

브리핑에서 나온 마감과, 캘린더·미리 알림으로 넘긴 일정을 한 달치 달력에 모읍니다. 날짜를 읽지 못한 항목은 아래에 따로 셉니다 — 달력에 없다고 해서 마감이 없는 것은 아니기 때문입니다.

> 사진 없음 — 같은 이유입니다.

## 설정 `⌘,`

여덟 개 탭입니다.

| 탭 | 무엇 |
|---|---|
| **브리핑** | 로컬 모델(이 Mac이 감당하는 것과 직접 지정) · 수집 범위 · 분석 품질 · 밤 자동 실행 |
| **연결 상태** | 소스마다 되는지 안 되는지, 안 되면 눌러 복사할 명령 |
| **분류 기준** | 무엇을 중요하게 볼지 문장으로 적어 두는 곳 |
| **전사** | ASR 모델 · 화자 구분 토큰 |
| **받아쓰기** | 전역 단축키 · 언어 · 자동 붙여넣기 |
| **도구** | 각 도구의 기본값과 저장 폴더 |
| **음악** | YouTube Data API 키 |
| **프린터** | 집 서버 주소 · 이 앱의 SSH 열쇠 등록 · 기본 프린터와 용지 |
