# 설정 — 무엇을, 어디에, 어떻게

이 앱은 **아무것도 설정하지 않아도 절반은 그대로 돌아갑니다.** 문서 인식(`빠름`)·스캔 보정·PDF 편집·용량 줄이기·형식 변환은 준비물이 없습니다. 아래는 나머지를 켜는 방법이고, **필요한 것만 골라** 하시면 됩니다. 안 한 항목은 조용히 빠질 뿐 다른 기능을 막지 않습니다.

> **지금 무엇이 켜져 있는지 확인하는 법**
> 앱을 열고 **설정(⌘,) › 연결 상태**를 보세요. 항목마다 되는지 안 되는지와, 안 되면 눌러서 복사할 명령이 함께 나옵니다. 창 없이 보려면:
> ```sh
> dist/SeoulLocalAgent.app/Contents/MacOS/SeoulLocalAgent --connection-check
> ```

---

## 1. 로컬 모델 (브리핑 분류·요약)

브리핑이 메일과 공지를 분류할 때 쓰는 모델입니다. Ollama가 이 Mac에서 돌립니다.

```sh
brew install ollama      # 없다면
ollama serve             # 백그라운드로 켜 둡니다
```

그다음 **자기 맥에 해당하는 줄 하나만** 받으세요. 앱이 메모리를 재서 알아서 고르므로, 어느 것을 받아야 하는지는 **설정 › 연결 상태**에 그대로 적혀 있습니다.

| 메모리 | 받을 모델 | 가중치 |
|---|---|---|
| 48 GB 이상 | `ollama pull qwen3.6:35b-a3b-nvfp4` | 22.0 GB |
| 36 GB 이상 | `ollama pull qwen3:30b-a3b-q4_K_M` | 17.3 GB |
| 32 GB 이상 | `ollama pull gpt-oss:20b` | 12.8 GB |
| 32 GB 미만 | 로컬 모델을 권하지 않습니다 | — |

메모리의 절반을 넘는 모델은 실패하지 않고 **조용히 느려지기만** 합니다. 그래서 32GB 미만인 맥에서는 앱이 Ollama에 묻기도 전에 "이 맥에서는 로컬 모델이 버겁습니다"라고 먼저 말합니다. 그래도 시도하고 싶으면 **설정 › 브리핑**에서 모델 이름을 직접 적으면 그 선택이 이깁니다.

## 2. macOS 권한

메시지·캘린더·미리 알림은 macOS가 처음 쓸 때 물어봅니다. **거부해도 됩니다** — 그 소스만 빠지고 나머지는 그대로 돕니다. 나중에 바꾸려면 시스템 설정 › 개인정보 보호 및 보안에서 켜세요.

전역 받아쓰기를 쓰려면 **손쉬운 사용**(키 입력 삽입)과 **입력 모니터링**(단축키 감지) 권한이 필요합니다. 앱이 처음 시도할 때 안내합니다.

## 3. Gmail — 읽기 전용

`gog`가 Google 계정에 붙고, 앱은 그것을 **읽기 전용으로만** 부릅니다. 메일을 보내거나 읽음으로 바꾸거나 지우는 경로는 앱에 없습니다.

```sh
brew install steipete/tap/gog     # https://github.com/steipete/gog
gog auth login                    # 브라우저에서 계정 승인
```

그다음 볼 주소를 이 파일에 적습니다. **파일이 없으면 직접 만드세요.**

```
~/Library/Application Support/SeoulLocalAgent/gmail-accounts.json
```

```json
[
  { "address": "you@snu.ac.kr", "mailboxIndex": 0 },
  { "address": "you@gmail.com", "mailboxIndex": 1 }
]
```

- `address` — `gog`에 이어 둔 계정 주소
- `mailboxIndex` — 계정을 여럿 쓸 때 `gog`가 매기는 순번. 하나만 쓰면 `0`

주소를 소스가 아니라 이 파일에 두는 이유는 그것이 개인 정보이기 때문입니다. 파일이 없으면 **Gmail만 0건으로 빠지고** 브리핑은 나머지 소스로 그대로 돕니다.

## 4. eTL — 과목 공지와 과제 마감

수업이 실제로 도는 `myetl.snu.ac.kr`은 **Canvas LMS**입니다. 문서화된 REST API가 열려 있어서, 앱은 화면을 긁지 않고 그 API만 읽습니다. 과제 마감이 문장이 아니라 `due_at` 필드로 오기 때문에 날짜를 추측할 필요가 없습니다.

### 토큰 발급

1. <https://myetl.snu.ac.kr> 에 로그인
2. 왼쪽 맨 아래 **계정(Account)** → **설정(Settings)**
3. 아래로 내려 **승인된 통합(Approved Integrations)** 항목의 **+ 새 액세스 토큰**
4. 용도에 아무 이름(예: `로컬 에이전트`)을 적고 생성
5. **토큰은 이때 한 번만 보입니다.** 복사해 두세요.

### 토큰 넣기

터미널에서 아래를 실행하고, 커서가 멈추면 토큰을 붙여 넣고 Enter를 누르세요. **입력한 값은 화면에 보이지 않습니다.**

```sh
security add-generic-password -U -s com.seoullocalagent.etl.token -a myetl -w
```

토큰은 계정 전체 권한을 가진 자격증명이라 저장소에도, 설정 파일에도 두지 않고 **Keychain에만** 들어갑니다. 명령에 값을 인자로 붙이지 않는 이유는 셸 기록에 남지 않게 하려는 것입니다.

### 확인

**설정 › 연결 상태**의 eTL 줄이 `2026-2학기 · 6과목 · 읽기 전용으로 응답합니다`처럼 학기와 과목 수를 말하면 된 것입니다. 학기 중인데 과목이 0개로 나오면 다른 계정의 토큰입니다.

> 온라인 강의 진도와 출석은 일부러 다루지 않습니다. 그쪽만 Canvas가 아니라 학교가 얹은 별도 레이어에 있어서 문서가 없고, 학교가 갱신하면 조용히 깨집니다.

## 5. Slack — 읽기 전용 (선택)

```sh
security add-generic-password -U -s kr.ac.snu.local-agent.slack -a read-token -w
```

같은 방식으로 커서가 멈추면 토큰을 붙여 넣습니다. 사용자 토큰(`xoxp-`)이면 자기 DM과 들어가 있는 채널을 읽습니다. 토큰이 없으면 Slack만 빠집니다.

## 6. 학교 공지 게시판

단과대·본부 게시판 20여 곳이 이미 등록되어 있고 대부분 켜져 있습니다. **설정 › 연결 상태**에서 목록 파일을 열어 자기 학과만 남기고 끄면 됩니다.

```
~/Library/Application Support/SeoulLocalAgent/web-notices.json
```

`enabled`를 `false`로 바꾸면 그 게시판은 수집에서 빠집니다. 공개 페이지만 읽으므로 로그인 정보는 필요 없습니다.

## 7. 녹음 화자 구분 (선택)

전사 자체는 준비물이 없지만, **누가 말했는지 가르려면** Hugging Face 토큰이 하나 필요합니다.

```sh
./scripts/setup-transcription-env.sh
```

1. <https://huggingface.co/pyannote/speaker-diarization-community-1> 에서 약관에 동의
2. <https://huggingface.co/settings/tokens> 에서 **읽기** 토큰 생성
3. 앱의 **설정 › 전사**에 붙여 넣기 (이 Mac의 Keychain에만 저장됩니다)

토큰이 없어도 전사는 그대로 됩니다. 화자 이름만 붙지 않습니다.

## 8. 음악 — YouTube 검색 (선택)

곡을 **찾는** 데만 YouTube를 씁니다. 소리는 광고가 없는 곳(이 Mac의 음악 파일 · Audius · Internet Archive)에서 먼저 찾고, 없을 때만 YouTube로 넘어갑니다.

1. <https://console.cloud.google.com> 에서 프로젝트를 하나 만들고
2. **YouTube Data API v3**를 사용 설정
3. 사용자 인증 정보 → **API 키** 만들기
4. 앱의 **설정 › 음악**에 붙여 넣기

키는 소스가 아니라 이 Mac의 파일에 저장됩니다.

```
~/Library/Application Support/SeoulLocalAgent/youtube-config.json
```

키가 없어도 **무료 음원 검색**(Audius·Internet Archive)과 **내 음악**은 그대로 됩니다.

## 9. 프린터 (선택)

집에 서버를 두고 프린터를 USB로 붙여 둔 경우에만 쓰는 기능입니다. 라즈베리파이면 충분합니다.

1. **설정 › 프린터 › 서버**에 주소와 계정을 넣습니다.
   - `집에서 쓸 주소` — LAN의 고정 IP나 호스트 이름
   - `집 밖에서 쓸 주소` — Tailscale 같은 사설망 주소 (비워도 됩니다)
   - 두 칸을 다 채우면 어디에 있든 먼저 열리는 쪽으로 붙습니다
2. **이 앱의 열쇠** 항목의 `등록 명령 복사`를 누르고, 그 명령을 터미널에서 한 번 실행합니다.

   앱은 `~/.ssh`를 읽지 않습니다. 터미널에서 되는 접속이 앱에서는 안 되는 이유가 그것이고, 그래서 이 앱만 쓰는 열쇠를 따로 만들어 서버에 등록합니다. 이 열쇠는 서버의 `authorized_keys`에서 언제든 지울 수 있습니다.
3. 프린트 화면에서 `새로고침`을 누르면 서버의 프린터 목록을 읽어 옵니다.

비워 두면 프린트 화면은 아무것도 하지 않고, 다른 기능에는 영향이 없습니다.

## 파일은 어디에 있나

전부 이 Mac 안에만 있습니다.

| 무엇 | 어디 |
|---|---|
| 브리핑 결과 (최근 90일) | `~/Library/Application Support/SeoulLocalAgent/briefing-archive.json` (권한 `0600`) |
| Gmail 계정 목록 | 같은 폴더 · `gmail-accounts.json` |
| 공지 게시판 목록 | 같은 폴더 · `web-notices.json` |
| YouTube 키 | 같은 폴더 · `youtube-config.json` |
| 프린터 서버 설정 | 같은 폴더 · `home-server.json` |
| eTL · Slack · Hugging Face 토큰 | **Keychain** (파일이 아닙니다) |
| 나머지 설정 | `UserDefaults` (앱 기본 설정) |

폴더를 여는 가장 빠른 길:

```sh
open ~/Library/Application\ Support/SeoulLocalAgent
```

### 전부 지우려면

```sh
rm -rf ~/Library/Application\ Support/SeoulLocalAgent
security delete-generic-password -s com.seoullocalagent.etl.token
security delete-generic-password -s kr.ac.snu.local-agent.slack
security delete-generic-password -s kr.ac.snu.local-agent.pyannote
defaults delete kr.ac.snu.local-agent
```
